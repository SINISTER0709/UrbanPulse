# UrbanPulse AI – Track D Frontend (Vite + React + TS + Tailwind)
1. `npm install`  2. `npm run dev` → http://localhost:5173
- Demo mode (default): `.env` has `VITE_USE_MOCK=true`, so no backend is needed. Use the demo buttons on the login page.
- Live mode: set `VITE_USE_MOCK=false`, restart, and run FastAPI on http://127.0.0.1:8080 (Vite proxies /api).
